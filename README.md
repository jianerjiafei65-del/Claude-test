## ひなたレシピ帳（`recipes/`）

自分のレシピと献立を記録・管理するサイトです。

- **レシピ**：写真、材料・調味料と分量、栄養成分（6項目）、調理時間（下ごしらえ・調理・待ち時間）、アレルギー、作り方、メモを登録できます。編集・複製・削除・お気に入りもできます。
- **一覧**：料理名と材料で検索できます。カテゴリと条件（お気に入り・15分以内・400kcal以下・ベジ）で絞り込み、並び替えもできます。
- **分量の計算**：詳細画面で人数を変えると、分量を自動で計算し直します。
- **献立**：週ごとに、朝・昼・夜・間食へレシピを追加できます。1日の合計（カロリー・たんぱく質・塩分）と、週の平均を表示します。
- **写真**：スマホのカメラやアルバムから登録できます。ブラウザ内で最大 1200px の JPEG に縮小して保存します。
- **保存**：データはブラウザ内（IndexedDB）にだけ保存されます。サーバーには送りません。「設定」から写真込みの JSON ファイルに書き出し・読み込みができるので、バックアップや別の端末への移動に使えます。
- **ファイル**：`index.html`、`style.css`、`app.js`、`samples.js`（初回に入るサンプル11品。数値は目安です）。

# Café Komorebi ホームページ

HTML / CSS / JavaScript だけで作った、カフェのホームページです（架空の店舗）。ビルドは不要です。

## 主な機能

- **スマートフォン対応**：スマホの画面を基準に作り、768px と 1024px で表示を切り替えます。スマホではハンバーガーメニューと画面下の固定ボタン（電話・お問い合わせ）を表示します。
- **メニュー紹介**：Coffee / Tea / Food / Sweets をタブで切り替えます。キーボードの矢印キーでも操作できます。
- **店舗情報**：住所、営業時間、定休日、アクセスなどを表示します。日本時間で「営業中／営業時間外」を自動で表示します。
- **お問い合わせ**：ボタンを押すとフォームが開きます。入力内容をチェックし、送信後に完了画面を表示します。

## ファイル構成

```
index.html     ページ本体
css/style.css  デザイン・レスポンシブ対応
js/main.js     メニューデータ、タブ、モーダル、フォームのチェックなど
```

## 表示方法

`index.html` をブラウザで開いてください。ローカルサーバーで確認する場合は次のコマンドを使います。

```bash
python3 -m http.server 8000
```

その後、http://localhost:8000 を開きます。

## カスタマイズ

- **メニュー**：`js/main.js` の `MENU_DATA` を編集します。
- **営業時間**：`js/main.js` の `HOURS` と、`index.html` の店舗情報を編集します。
- **色**：`css/style.css` の `:root` にある変数を変更します。
- **地図**：`index.html` の `.map-placeholder` を Google マップの埋め込みコード（iframe）に差し替えます。
- **お問い合わせの送信**：今はデモ用で、実際には送信されません。`js/main.js` の送信処理に、フォームサービス（Formspree など）や自前の API への `fetch` を追加してください。
